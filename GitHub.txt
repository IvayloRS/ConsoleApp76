Работата с GitHub обикновено включва два вида инструменти: стандартния Git (за управление на версиите) и GitHub CLI (за управление на функциите на GitHub като Pull Requests и Issues директно от терминала). 
1. Основни Git команди (The Core Workflow) 
Тези команди се използват за ежедневно управление на кода и синхронизация с отдалеченото хранилище (remote repository). 
Команда 	Описание
git init	Инициализира ново локално Git хранилище.
git clone [url]	Копира съществуващо хранилище от GitHub на вашия компютър.
git status	Показва състоянието на работната директория и кои файлове са променени.
git add [file]	Добавя конкретен файл към "staging" зоната (подготовка за запис).
git add .	Добавя всички променени файлове в текущата директория.
git commit -m "съобщение"	Прави "снимка" на промените и ги записва локално с описание.
git push	Качва локалните промени (commits) в отдалеченото хранилище в GitHub.
git pull	Изтегля и обединява промените от GitHub в локалния ви компютър.
2. Клонове и обединяване (Branching & Merging)
Позволяват работа по нови функции, без да се разваля основния код.
Създаване на клон: git branch [име-на-клон].
Превключване към клон: git checkout [име-на-клон] или модерното git switch [име-на-клон].
Създаване и превключване едновременно: git checkout -b [име-на-клон].
Обединяване: git merge [име-на-клон] – влива промените от посочения клон в текущия. 
3. GitHub CLI (gh) – Команди за платформата 
Ако имате инсталиран GitHub CLI, можете да управлявате GitHub функции без браузър: 
Хранилища: gh repo create (създаване) или gh repo fork (копиране на чуждо хранилище).
Pull Requests: gh pr create (създаване на заявка за преглед) или gh pr list (списък с отворени PR).
Issues: gh issue list (списък със задачи) или gh issue create (създаване на нова задача).
